PR description:

```
Adds speak-when-done to Text-to-Speech.

A small local MCP server (Node, zero dependencies) with two tools, `speak` and `notify_done`, that says out loud
when a coding agent finishes or needs input. It uses the system voice on macOS, Windows and Linux, any language,
no API keys, no telemetry. Optional: speak on a smart speaker through DuoWave.

Glama: https://glama.ai/mcp/servers/duowaveai/speak-when-done
```
